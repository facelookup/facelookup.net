# Face Lookup

[Face Lookup](https://facelookup.net/) is a reverse face search tool for exploring where an authorized portrait may appear on public web pages.

Upload a portrait you own or have permission to search, review available visual matches, and open original source links when provided. Coverage varies, and results do not verify anyone's identity.
